## 📖 Overview

**Diff Bot** is a ruthless, automated Discord utility bot built in Python. It binds a user's Discord account to their Riot ID, actively monitors their League of Legends Solo/Duo LP, and serves up customized, PG-13 roasts generated by an advanced AI model when they perform terribly. 

Whether someone is locking in Jhin and forgetting how to count to four, or taking Jax top and going 2/10, Tilt Tracker ensures their mechanical incompetence and negative LP deltas are broadcasted to the entire server.

## ✨ Features

* **📉 LP Delta Tracking:** Actively polls the Riot API to track LP gains and devastating losses in real-time.
* **🔥 Dynamic AI Roasting:** Leverages NVIDIA NIM (Nemotron-3) to analyze match data—KDA, duration, and outcome—to generate personalized, context-aware roasts.
* **💾 Database Persistence:** Robust SQLite integration mapping multiple servers, linked users, and historical LP data.
* **⚙️ Background Async Polling:** Runs on a seamless, non-blocking asynchronous loop to ensure core Discord bot functionality remains lightning fast.

## 🛠️ Tech Stack

* **Language:** Python 3.10+
* **Libraries:** `discord.py`, `aiohttp`, `sqlite3`, `openai` 
* **External APIs:** 
  * Riot Games API (Account-V1, Summoner-V4, League-V4, Match-V5)
  * NVIDIA NIM API (nvidia/nemotron-3-super-120b-a12b)
